# Session 6 design, extended for Session 7

[Parking Permit Lookup](parking_permit_lookup.md) is a repository copy of the
draft by Laksh and Aaron supplied as `Copy of design_doc_template.md` in
Downloads. Its previously blank Capacity and Proposed design sections now
contain explicitly labeled planning assumptions, followed by the Session 7
Scaling and Failure modes sections. The original Downloads file is unchanged.

The calculations and assumption sources are recorded in
[Week 7 scaling calculations](../week7_scaling/scaling_calculations.md).
Practice machine limits come from Section 10.3 of the supplied System Design
Handbook. The official standalone template and URL-shortener example were not
provided; the source draft supplies the headings and four failure-table
columns, and the handbook supplies the worked example in Part 15.
